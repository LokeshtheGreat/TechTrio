# ML-Based Heart Disease Risk Estimator

> A machine learning application designed to estimate heart disease risk based on clinical parameters and health indicators.

---

## 1. Project Overview

The **ML-Based Heart Disease Risk Estimator** is developed as part of `TechTrio-Month-2` (Project 3). It aims to deliver reliable risk estimation by training and evaluating machine learning models on validated cardiovascular health datasets, exposed via a backend API service and an interactive user interface.
